# Deveb.co Hero Section Clone (Old Version) 🚀

This is a **mini project** where I recreated the hero section of the previous version of the award-winning website [Deveb.co](https://deveb.co/). The goal was to practice advanced front-end techniques, creative animations, and canvas-based visual effects.

## ✨ Features

- 🔹 Smooth scroll and entry animations using **GSAP**
- 🌀 Interactive canvas background powered by **Three.js** with noise shaders
- 🎯 Sticky section with centered bold typography and animated subtext
- ⚡ Built using **Tailwind CSS** for rapid styling
- 📱 Responsive and clean layout

## 📚 What I Learned

- Integrating **GSAP timelines** for animated text transitions
- Setting up a **Three.js canvas** with shader-like noise effects
- Layering elements using `z-index` and Tailwind positioning
- Enhancing user experience with scroll-sticky interactions

## 🚧 Still Improving...

I’m still in the learning phase and continuously improving the UI/UX, performance, and code structure. Future plans include:
- Adding scroll-triggered animations
- Improving performance of the canvas animation
- Making it fully mobile-optimized

## 🧪 Tech Stack

- **HTML5**
- **Tailwind CSS**
- **JavaScript (ES6)**
- **GSAP**
- **Three.js**
